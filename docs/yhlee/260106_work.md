## 이슈
antigravity 와 cursor 두개를 모두 띄워놓고, 동일한 작업 폴더를 오픈 했다.

터미널에서, 다음과 같이 가상환경을 생성하고 활성화 하였다.
```
python3 -m venv .venv
. .venv/bin/activate
```

그 다음, 예제 .ipynb 파일 하나를 각각의 에디터에서 열고,
Select Kernel 을 하여 .venv/ 폴더의 python 3.14 환경을 선택했다. 
커널 연결은 두 에디터 모두 다 잘 된다.

그런데 cursor의 경우, 바로 ipynb 노트북의 play 버튼을 눌러 실행이 되는 반면
antigravity는 자꾸 jupyter notebook 패키지를 설치하라고 한다. 아래의 에러 메시지 참고.
```
Running cells with '.venv (Python 3.14.0)' requires the notebook package.
...
```

여기서 취소를 누르면 아래와 같은 에러로 중단된다.
```
Jupyter cannot be started. Error attempting to locate Jupyter: Running cells with '.venv (Python 3.14.0)' requires the notebook package.
Install 'jupyter and notebook' into the Python environment. 
Command: 'python -m pip install jupyter notebook -U
or
conda install jupyter notebook -U'
Click here for more info.
```

ipykernel 패키지는 가상환경 내부에서 pip으로 설치는 해 놓은 상태이다.
왜 두 에디터가 서로 다른 차이를 보이는가?
